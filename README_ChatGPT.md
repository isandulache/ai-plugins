# chatgpt-plugins

Julien SANDULACHE's ChatGPT plugins, skills, agent and other tools.

## Installation

Download the .zip file of the latest [release](https://github.com/isandulache/ai-plugins/releases) from the GitHub repository.

**Web** (in the ChatGPT interface):

1. Go to the ChatGPT settings.
2. Navigate to the "Plugins" section.
3. Enable the plugin marketplace.
4. In the upper right corner, click on the "Add" button and choose `Upload Plugin Archive`.
5. Search for the file you downloaded (the .zip file) and add it.
6. Click on `Add plugin` button.
